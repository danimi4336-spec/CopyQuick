# Customer terminology

CopyQuick uses the following customer-facing vocabulary consistently across public, account, planning, and Production surfaces.

| Term | Meaning |
| --- | --- |
| **Credit** | One unit from the customer’s monthly allowance. Creating one ready-to-use asset uses one credit. Supporting documents use no credits. |
| **Production** | The guided process that creates approved assets and supporting documents. Production is a workflow, not a type of credit. |
| **Ready-to-use asset** | Finished customer-facing work that can be reviewed, copied, downloaded, and used. |
| **Supporting document** | Planning, research, or strategy work that guides an asset. It is included without using credits and is not customer-facing copy. |
| **Content History** | The customer’s saved content records. “Generation” remains an internal implementation term and may appear only where technically necessary. |

Avoid customer-facing variants such as “AI Credits,” “Production credits,” “output deliverables,” “ready assets,” and billing estimates expressed as “generations.” Internal identifiers, database columns, route names, and provider telemetry do not need to adopt this vocabulary.
